Desktop Settings: draft

Feeds are added, edited and removed only in Settings, as on the phone (D27). Settings is its own mode that takes the whole window: the sidebar shows the Settings sections instead of streams and feeds, and the right-hand area shows the chosen page, which pushes further pages as the phone does (Edit Feed, Edit Folder), with back and a centred title. Same groups, rows, chips and sheets as M5–M11, at desktop type sizes (13.5 rows, 36 pt high). HTML recreations with the Sand tokens, not screenshots.

What changes, what stays

  • Moves to Settings: Add Feed (title-strip button, ⌘N / Ctrl+N), Edit…, Remove Feed… and folder Edit… from the sidebar menus, Import/Export from the menus, the theme and list-order menu items.
  • Stays where it is: reading (streams, list, article), Mark All as Read, Open Website, Refresh, the filter bar.
  • Shared with the phone: SettingsViewModel, ManageFeedsViewModel, the panel view-models and ImportFeedsViewModel (W2). Desktop gets its own views at desktop sizes; the overlay panels (A6) go.
  • Open: ⌘N could stay as a shortcut that opens Settings › Add Feed directly. The macOS menu bar could keep its View ▸ Theme items as shortcuts to the same settings.
